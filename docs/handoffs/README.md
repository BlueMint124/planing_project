# Handoffs

기능별 작업 맥락을 다른 개발자와 Codex에 전달하는 문서를 저장한다.

- 파일명은 `<feature-name>.md` 형식을 사용한다.
- 새 문서는 `docs/collaboration/handoff-template.md`를 복사해 작성한다.
- 기능 브랜치를 푸시하거나 Pull Request를 갱신하기 전에 handoff 문서를 갱신한다.
- 구현 세부사항보다 다음 작업자가 알아야 할 결정, 계약, 검증 결과, 남은 작업을
  우선 기록한다.
- 기능이 완료되어도 문서를 삭제하지 않는다. 이후 작업의 맥락과 결정 이력으로
  사용한다.
