# Collaborator Prompt: Trip Input UI

```text
AGENTS.md와 docs/collaboration/prompts/collaborator-start.md의 규칙을 따라줘.

이번 작업 기능은 여행 조건 입력 UI야.
브랜치는 codex/trip-input-ui를 사용해.

구현 범위:
- 모바일 우선 단계형 입력 화면
- 지역 입력
- 여행 기간 preset 선택
- 1인당 예산 입력
- 2명부터 10명까지 인원 선택
- 다음과 이전 버튼
- 저장소의 공통 폼 타입과 mock 데이터 사용
- 관련 컴포넌트 테스트

제외 범위:
- 여행 스타일과 멤버 선호 UI
- 실제 API 호출
- 서버 입력 검증
- AI 생성
- 지도와 결과 화면
- 공통 타입 및 계약 변경

완료 조건:
- 사용자가 지역, 기간, 예산, 인원을 입력하고 단계 사이를 이동할 수 있다.
- 모바일 화면에서 입력 요소가 깨지지 않는다.
- 공통 타입과 mock 데이터만 사용한다.
- 관련 테스트가 통과한다.
- work-board와 docs/handoffs/trip-input-ui.md를 갱신하고 브랜치를 push한다.
```
